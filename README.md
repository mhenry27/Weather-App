# Weather App — iOS Weather & Travel Companion

## Project Overview

Weather App is an iOS application developed using Swift and SwiftUI that combines weather forecasting with travel planning features. Users can search for cities, view detailed weather conditions, customize their experience, and receive recommendations based on upcoming weather.

Developed as part of the PM Accelerator internship, this project demonstrates iOS application development, API integration, user interface design, and application state management.

## Technologies Used

- **Swift** — Application logic and functionality
- **SwiftUI** — User interface development
- **Xcode** — Development and debugging
- **Weather API** — Weather forecasts and current conditions
- **REST APIs & JSON** — Data retrieval and processing

## Key Features

### Weather Forecasting
- Search for weather conditions in cities around the world
- View current temperature and weather conditions
- Explore hourly weather forecasts
- View high and low temperatures
- Access additional weather details, including UV information

### City Management
- Save multiple cities for quick access
- Reorder saved cities
- Remove cities using swipe-to-delete
- Display current weather information for saved locations

### Travel & Lifestyle Features
- Personalized packing suggestions based on weather conditions
- Outfit and clothing recommendations
- Weekend planning features
